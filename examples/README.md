# Examples

This directory will hold ready-to-open `.blend` scenes and step-by-step
recipes for common Gaussian Mesh Editor workflows.

Planned examples:

| File | Shows |
| --- | --- |
| `proxy_cage.blend` | A KIRI-style Gaussian EMPTY + a proxy cage, bound and ready to deform with Auto-Follow ON |
| `mesh_gaussian.blend` | A MESH-representation Gaussian (splat centers as vertices) with a fitted proxy |
| `binding_stats.blend` | A scene illustrating `Surround Cams` coverage effects on binding stats |

Until the scenes are added, follow the written walkthrough in
[docs/usage.md](../docs/usage.md) — it covers the same steps end to end.
